# FishFinder ROV Mobile App

Native Android APK for FishFinder ROV.

## Features
- **Touch Screen Swipe Camera Control**: Swipe on the screen to Pan Left/Right and Tilt Up/Down.
- **Zero-Latency Video**: Direct 720p 30 FPS stream from Raspberry Pi.
- **Full-Screen Immersive Mode**: Seamless landscape ROV controller experience.

## Download APK
Go to the **Actions** tab -> click the latest build -> download **FishFinder-ROV-App** (`app-debug.apk`).
